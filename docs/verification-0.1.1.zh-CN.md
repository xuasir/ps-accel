# PS Accel 0.1.1 验证记录

验证日期：2026-11-23。开发环境：macOS、Python 3.13.3、Scapy 2.6.1。部署目标：FastRhino R66S / rockchip/armv8 / OpenWrt 25.12-SNAPSHOT / Linux 6.12.115。

## 自动化检查

110 项测试通过，覆盖原协议、OpenWrt 主控、LuCI 管理、部署与本次优化。

| 场景 | 结果 |
| --- | --- |
| 日志和状态文件写入抛出异常 | 40 个测试启动包继续转发，恢复完成，错误计入诊断健康信息 |
| 后台状态写入阻塞 | 转发继续，诊断关闭在设定等待时间后返回 |
| 日志队列积压 | 队列容量保持有界，旧日志舍弃，统计快照保留最新值 |
| 中文与超长事件记录 | 文件大小遵守轮转上限，保留 2 份备份，UTF-8 内容有效 |
| 恢复报告写入失败或阻塞 | 网络恢复标记与引擎锁先释放，报告写入在后台处理 |
| 控制元数据写入失败 | 主控终止已创建的引擎并等待其退出 |
| 运行中换档 | 按停止、恢复、保存、启动顺序执行，开机启动偏好保留 |
| 新档位启动失败 | 尝试恢复原档位与服务，原始错误及回退错误保留 |
| 换档期间取消 | 完成停止与恢复，后续保存或启动按取消阶段结束 |
| 陈旧统计、PID 复用和旧就绪标记 | 运行状态由当前进程身份、命名空间和启动标记决定 |
| 安装与卸载 | 模拟路由器验证权限、配置保留、互斥锁和安装清单 |
| 原生 OpenWrt 包配方 | SDK 桩验证引擎、后台诊断模块、LuCI 与 RPC 安装位置 |

LuCI JavaScript、预览 JavaScript、安装器、卸载器、服务入口与 RPC shell 入口语法检查通过。

## 页面检查

预览加载与安装包相同的 LuCI 页面代码，操作使用演示数据。

- 1280 像素桌面：四张状态卡同排，状态下方 Tab，控制面板双栏。
- 390 像素手机：五个码率档位可见，深浅色主题与 Tab 正常。
- 320 像素窄屏：三个 Tab 的内容宽度保持在视口内，设备表单改为单栏。
- 运行中保存 100 Mbps：自动重启完成提示出现，开机启动选项保留。
- 模拟采样延迟和写入异常：状态卡继续显示运行，日志诊断展示记录健康信息。
- 浏览器控制台错误记录为空。

诊断 JSON 内容和脱敏已通过后端测试。浏览器自动化的下载事件等待超时，下载动作的端到端验收保留在实际 LuCI 浏览器中执行。

## R66S 验收

新版当前完成本地源码、模拟路由器和演示页面验证。R66S 实机安装、冷启动、游戏体验与 CPU 观测按 [安装说明](../openwrt/README.zh-CN.md) 执行；原生 APK 使用同版本固件构建树生成。

建议从 65 Mbps 完成连接测试和 90 秒试运行，随后在运行中切换 45 / 100 Mbps，确认自动恢复、重启和 Portal 重新连接，并检查开机启动偏好。
