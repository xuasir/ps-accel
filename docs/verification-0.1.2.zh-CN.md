# PS Accel 0.1.2 验证记录

验证日期：2026-11-23。开发环境：macOS、Python 3.13.3、Scapy 2.6.1。部署目标：FastRhino R66S / rockchip/armv8 / OpenWrt 25.12-SNAPSHOT / Linux 6.12.115。

## 修复与验证

144 项 Python 测试和 12 项 LuCI JavaScript 回归测试通过，共 156 项。Python 测试涵盖原协议、转发与恢复、OpenWrt 主控、管理任务、部署及安装文件；JavaScript 测试通过模拟 RPC、DOM 和请求截止时间验证实际 LuCI 页面代码。

| 场景 | 验证结果 |
| --- | --- |
| 启动就绪超时 | 发出的服务启动请求进入停止恢复流程，任务结束为失败，页面解除任务占用 |
| 启动状态查询异常与取消交错 | 停止恢复仍执行，原始错误保留，取消标记清理完成 |
| 初始请求耗尽启动期限 | 启动期限从请求前开始计算，子进程请求时间纳入期限 |
| 任务记录写入失败 | 已创建的真实测试子进程被终止并回收；等待启动的管理进程也有同类回收保护 |
| 子进程超时或忽略 SIGTERM | 使用有界退出等待，超时后终止该子进程；独立恢复进程继续使用其恢复路径 |
| 新档位与原档位均启动失败 | 原始错误和回退错误分别保留，最后一次启动请求完成停止恢复 |
| 清理失败时再次点击停止 | 任务结束为失败，停止恢复执行一次，错误保留，页面允许再次操作 |
| 接口已删除、命名空间删除失败 | 保留资源归属记录，下一次恢复只清理仍存在且归属匹配的资源 |
| 命名空间已删除、接口仍存在 | 校验接口别名及 ifindex 后继续清理 |
| 归属记录删除失败 | 资源删除后仍可再次清理残留记录 |
| 准备阶段创建接口失败且清理失败 | 已创建命名空间的身份提前保存，后续恢复可继续处理 |
| 剩余资源被替换、恢复尚待确认 | 资源保留，错误及时返回 |
| 孤立子进程尚未退出 | 每次停止重试保留原进程身份，界面提供停止入口并等待其退出 |
| 旧任务失去所有权 | 新管理任务的状态与服务保持由新任务控制 |
| 完整 UDP 启动消息带 IP 尾部数据 | 保持原 IP 报文转发；标准精确长度消息继续改写，IP/UDP 长度与校验和正确 |
| 进程查询失败、命名空间删除竞态 | 状态响应保持可读取，查询错误独立显示，恢复入口可重试 |
| 页面请求始终没有响应 | 12 秒后解除本次请求的页面占用 |
| 日志读取阻塞 | 动态状态继续刷新，服务操作保持可用 |
| 日志与状态写入失败或阻塞 | 既有转发和恢复隔离测试继续通过 |

## 轮询开销

在有效配置、有效连接测试和开机启动启用的模拟环境下，记录状态处理函数发出的外部命令、代码指纹调用和日志读取。

| 每 3 秒的动态状态请求 | 0.1.1 | 0.1.2 |
| --- | --- | --- |
| 直接外部命令 | 13 次 | 命名空间存在时 1 次，查询期限 2 秒 |
| 完整引擎代码指纹 | 2 次 | 0 次 |
| 日志尾部读取 | 最多 24000 字节 | 0 字节 |

首次加载、操作后或配置、程序修订变化时，页面调用 `details`：一次读取 UCI，复用配置对象，完整基线校验只计算一次引擎指纹。日志 Tab 可见时调用 `logs`，只读取当前所选日志末尾最多 12000 字节。配置修订标记根据文件元数据生成；启动前仍执行完整内容指纹和基线证据校验，代码变化会阻止使用旧测试记录启动。

这些数字表示本地代码路径的调用次数，R66S 的 CPU 与延迟变化通过实机观测验收。

## 页面检查

本地浏览器预览加载安装包使用的同一份 LuCI 页面代码，模拟恢复失败后显示“清理待重试”，恢复按钮可用。点击“恢复网络”后，任务结束、状态恢复为“已停止”，维护操作重新可用。

截图：[清理失败后的重试入口](../openwrt/preview/cleanup-retry-0.1.2.jpg)。页面顶部明确标注演示数据。

页面自动化回归还覆盖隐藏日志 Tab 的按需读取、进程查询错误、RPC 连接恢复、较早请求结束后的占用隔离、只读权限、配置修订更新、首次配置读取失败后的恢复，以及编辑中的设备设置保留。

LuCI JavaScript、预览 JavaScript、安装器、卸载器、服务入口和 RPC shell 入口语法检查通过。

## R66S 部署验收

按 [安装说明](../openwrt/README.zh-CN.md) 使用脚本包升级。新包控制器可在安装前执行停止恢复，处理旧版留下的部分网络资源；卸载默认保留配置和设备配对。升级后重新完成连接测试。

在主路由上验证常驻中继停止、运行中换档、失败后的恢复重试、开机启动偏好和实际游戏体验，记录 CPU 与延迟。当前完成的验收范围为本地源码、故障注入、模拟路由器、浏览器预览和安装文件；R66S 安装、冷启动与真实串流属于实机验收。
